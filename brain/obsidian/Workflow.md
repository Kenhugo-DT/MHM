# Workflow

1. Let the research agent create review candidates.
2. Approve useful candidates in Supabase.
3. Promote/import approved candidates into the graph.
4. Export the graph to Obsidian.
5. Use Obsidian to improve zones, eras and layout hints.
6. Import Obsidian metadata back into the graph build.
7. Run the audit and build checks.

The public site should only receive reviewed graph JSON, never raw research.
